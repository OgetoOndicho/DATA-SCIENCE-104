## PROJECT TITLE: STUDENT'S COLLEGE PLACEMENT CLASSIFICATION

## Problem Statement: 
- This project aims to develop a Classification Algorithm to enable stakeholders at Trademark College Kenya to make accurate Classifications on Student's placement from high school level to college

## Objectives:
- To develop a model that classifies correctly the number of students placed to college and the number of students not placed to college based on academic and behavioral factors.

## Project Outline
1. Data Preprocessing: Importing, reading and storing the dataset.
2. Cleaning and proper structuring of the dataset.
3. Feature Selection to enable model building.
4. Handling Categorical by converting the Target Variable [Placement Status] into a Numeric Feature.
5. Model Building {Use of Logistic Regression}
6. Model Evaluation. Used a Confusion Matrix and Accuracy Score as the Main Metrics to evaluate the model at making predictions on Students' College Classification.


## Data Source
- The dataset was obtained from a secondary source through the Kaggle Platform: https://www.kaggle.com/datasets/shambhurajejagadale/student-performance-prediction-dataset
